# Suricata IDS Analysis



Suricata is deployed on pfSense as a network intrusion detection system.



It monitors traffic originating from the USERS network.



## Rule Sources



ET Open rules were enabled to detect suspicious and known network activity.



## Detection Test



An Nmap scan was generated from USER-PC-01 toward the DMZ web server.



Source:



`10.20.20.10`



Destination:



`10.10.10.10`



Suricata generated a real ET Open alert:



`ET SCAN Possible Nmap User-Agent Observed`



This validated that Suricata was correctly inspecting the traffic and matching IDS signatures.



## Wazuh Integration



Suricata events are forwarded to the Wazuh server through syslog.



A custom Wazuh decoder named `suricata-eve` was created to identify Suricata EVE JSON events.



A local Wazuh rule was also created:



- Rule ID: `100101`

- Level: `7`

- Description: `Suricata IDS alert detected`



The rule matches Suricata events where:



`event\\\\\\_type = alert`



## Detection Pipeline



`Network Traffic → Suricata → Syslog → Wazuh Decoder → Wazuh Rule → SIEM Alert`



## Validation



The Nmap alert generated by Suricata was successfully received and detected by Wazuh through rule `100101`.



Suricata remains in IDS mode in the final project.



IPS mode is considered a future improvement after signature tuning and false-positive evaluation.
